# Country ISO and Catalog health source-parity diagnostics

Ten bounded native cases retain original synthetic evidence and assert exact source literals. Seven Country cases use normal authenticated POST, fresh GET, repeated POST, same-payload PUT, another fresh GET and a new independent own-Country database readback. Repeated POST creates separate IDs/two rows; Accounting idempotency is not imported. They cover empty, short, trailing-space, null, BMP/supplementary boundaries and whitespace. Normal Program intentionally omits nullable DTO properties through WhenWritingNull; this nullable wire behavior is preserved.

Every case retains all original response bytes, a fresh post-PUT database serialization and a diagnostic observation BEFORE the exact requested-versus-fresh/stored assertions. The current fixed-width model is expected to produce genuine source-parity RED where literals collapse; passing diagnostic observations cannot replace those assertions. A RED run must remain open until the smallest source-compatible correction and matching tests pass. The native verifier never seals a successful receipt for failing/skipped cases.

Exports require the exact current VSTest results child directory inside GITHUB_WORKSPACE, check all existing symlink/reparse ancestors before and after directory creation, use fixed bounded filenames, and refuse replacement. Native/full forecast10/345 and exact48 exports are verified together with unique execution inventories, all16 counters, identical raw coverage copies, immutable source hashes and original byte hashes. Historical receipts use the trusted current verifier with immutable Git data, never historical code execution.

The source Country model has maximum lengths without fixed-width configuration; the target model uses character(2)/character(3). Country currently uses an independent EnsureCreated schema, while consolidated Catalog uses migrations. A Catalog-only migration cannot correct the actual Country role. No migration or historical conversion is performed here; any correction needs an owned-Country schema updater and authoritative preimage handling without trim/guess. Country, Catalog and Currency data roles remain separate.

Three anonymous health cases inspect /catalog/liveness, /catalog/readiness and the old Material prefix. The old prefix may match protected CRUD, so it must not act as an anonymous healthy Catalog endpoint; a 404 is not assumed. These cases do not prove delayed startup, the original eb11c81a6c759e1d4bcd1a1b3b28dc5f30cc02cb 300-second rollout budget, Kubernetes behavior or deployment. Controlled JWT/owned PostgreSQL is not an actual Auth producer join. No full native result or candidate is claimed by this source draft.
